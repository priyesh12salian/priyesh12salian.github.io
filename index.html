Case Studies

Case study 1

AI agents inside NetSuite

MCP-connected assistants that reconcile bank lines and route purchase approvals, with a live React dashboard.

  • NetSuite MCP
  • RESTlet
  • Prompt Engineering
  • React
View details
Problem
Finance and purchasing teams spent hours on repetitive checks: matching bank lines, chasing purchase approvals, validating records before entry.
Approach
Built AI assistants on an MCP server connected to NetSuite RESTlets, with prompt logic for decision support such as bank reconciliation and purchase approvals. A React dashboard shows what each agent did and where every workflow stands.
Result
Routine validation, record creation, and follow-up communication now run through the agents, with humans approving exceptions instead of doing every step.

Case study 2

Manufacturing module implementation

Work orders, routings, BOMs and costing brought into NetSuite for a discrete manufacturer.

  • Manufacturing
  • Work Orders
  • SuiteScript
  • SuiteAnalytics
View details
Problem
A discrete manufacturer was tracking production outside NetSuite. Material usage, completions, and costs were reconciled by hand.
Approach
Configured work orders, assemblies, routings, BOMs, and work centres. Automated material issue and completion tracking with SuiteScript and workflows. Connected manufacturing data to procurement and inventory.
Result
End-to-end production visibility in one system, with costing and production efficiency dashboards in SuiteAnalytics and Power BI.

Case study 3

Suitelet web apps for HR processes

Timesheets, payroll and leave handled in NetSuite-backed web apps, with no NetSuite licences needed.

  • Suitelet
  • Custom Records
  • Available Without Login
  • UI
View details
Problem
Every employee who needed to log time or apply for leave required a NetSuite licence and training, which was expensive and slow to roll out.
Approach
Built a set of Suitelet-based web apps: login, dashboard, timesheet, payroll, and leave management. Users authenticate through the login Suitelet and work in a simple UI, while data lands in custom records inside NetSuite.
Result
Staff work in NetSuite-backed apps without NetSuite credentials or licences. HR data stays in one system of record.

Case study 4

Power BI dashboards over ODBC

Live finance dashboards in Power BI over ODBC, cutting manual reporting by about 40%.

  • Power BI
  • ODBC
  • SuiteQL / SQL
  • Finance
View details
Problem
Leadership wanted live financial analytics, but reports were exported to spreadsheets and rebuilt every period.
Approach
Connected Power BI to NetSuite through ODBC and SuiteAnalytics Connect. Authored the SQL queries, built the datasets, and automated workbook refreshes.
Result
Real-time balance sheet, income statement, AR and AP dashboards. Manual reporting workload down by about 40%.
