# priyesh12salian.github.io

Personal site of Priyesh Salian, NetSuite Techno-Functional Consultant.
Hosted on GitHub Pages at https://priyesh12salian.github.io

Static site: plain HTML, CSS and JS. No build step.

- `index.html` — content
- `css/style.css` — styles, colour tokens in `:root`
- `js/main.js` — nav, reveal, counters, typing effect

Preview locally:

```bash
python3 -m http.server 8000
```
