# priyesh12salian.github.io

Personal landing page, hosted on GitHub Pages at https://priyesh12salian.github.io

Static site: plain HTML, CSS and JS. No build step.

- `index.html` — page content (look for `<!-- EDIT -->` comments)
- `css/style.css` — styles and colour tokens in `:root`
- `js/main.js` — footer year and scroll reveal

Preview locally:

```bash
python3 -m http.server 8000
```
