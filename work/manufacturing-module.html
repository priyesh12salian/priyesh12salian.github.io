Case study 2

Manufacturing module implementation

Work orders, routings, BOMs and costing brought into NetSuite for a discrete manufacturer.

  • Manufacturing
  • Work Orders
  • SuiteScript
  • SuiteAnalytics

Problem

The problem

A discrete manufacturer was running production outside NetSuite. Material usage, completions and costs lived in spreadsheets and were reconciled by hand at month end, so nobody had a current view of what a build actually cost.

Step 1

Configure the model

We set up assembly items, multi-level BOMs, routings and work centres, then work orders that pull from them. Standard NetSuite where it fit, with custom fields only where the shop floor needed something the platform did not have.

Step 2

Automate the shop floor steps

SuiteScript and workflows handle material issue when a work order is released and completion tracking as operations finish. Operators record what happened; the system posts the inventory and WIP movements.

Step 3

Connect costing to the rest of the business

Production data now feeds procurement and inventory directly. Costing and production efficiency dashboards run in SuiteAnalytics, with finance views in Power BI over ODBC.

Result

The result

End-to-end production visibility in one system. Planned versus actual cost per build is available the day the build closes, and month-end reconciliation of production disappeared.
